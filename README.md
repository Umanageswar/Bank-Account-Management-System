# Bank-Account-Management-System

A terminal-based Bank Account Management System developed using Python and MySQL.

## Features

- Create Account
- User Login
- Check Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Change PIN
- Input Validation
- MySQL Database Integration

## Technologies Used

- Python
- MySQL
- SQL
- mysql-connector-python

## Database

The application uses MySQL to store:

- Account details
- Account balance
- Transaction history

## How to Run

1. Install Python.
2. Install MySQL Server and MySQL Workbench.
3. Create the `bank_management` database.
4. Create the `accounts` and `transactions` tables.
5. Install the MySQL Python connector:

```bash
pip install mysql-connector-python
